可溯源不是附加功能，是培训答疑的合规前提

⚙️ 核心机制

  • 可溯源 RAG：每个答案指回原始文档 / 课程 / 页码
  • 角色权限前置过滤：检索层带组织 + 岗位标签
  • 四类转人工触发：低置信度 / 红线规则 / 用户主动 / 追问升级
  • 知识沉淀闭环：未命中 → 讲师回复 → 确认入库
  • 有效期与责任人：知识块不腐化

🚫 明确不做的事

  • 不替代带教：AI 接事实问答，人做追问与纠偏
  • 不回答红线问题：退费 / 合同 / 安全 / 人事处罚 / 法律
  • 不生成无依据的「大概」：答不了就转人工
  • 不做「自信的猜测」：说错一句就是投诉
